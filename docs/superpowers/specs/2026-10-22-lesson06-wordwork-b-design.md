## 4. 活動

### 4.1 短語短句（phrase）
依序進行，一次做完：
1. **認識短語**：「閃亮亮的鉛筆」拆成「閃亮亮（怎麼樣）＋的＋鉛筆（東西）」，各部分有顏色、可點來聽。
2. **看圖選疊字**（8 題）：題目是圖＋「＿＿＿的蘋果」，4 個疊字選項（文字、不配圖），例如紅通通、黑漆漆、綠油油、灰濛濛。
3. **看圖說說看**（2 題）：學生對著圖說「＿＿＿的＿＿」。說法在 `accept` 清單裡就直接判對；不在清單但符合「三個字以上＋的＋東西」就等老師批改。
4. **認識語詞**：混合、斷裂，各有圖、意思。
5. **哪一句用得對**（4 題）：兩個句子二選一。
6. **說一句話**（2 題）：用「混合」、「斷裂」各說一句。檢查：有說到這個語詞、全句 6 個字以上 → 等老師批改。

### 4.2 句型（pattern）
進入後先選句型：「只要……就……」或「如果……不但……還……」。每個句型：
| 步驟 | 內容 | 題數 | 判定 |
|---|---|---|---|
| 1 | 認識句型：圖卡＋2 個例句，關聯詞有顏色，全程可聽 | — | — |
| 2 | 前後配對：給前半句，選合理的後半句（3 選 1） | 3 | 系統 |
| 3 | 選關聯詞：句子有空格，選正確的關聯詞組（3 選 1） | 3 | 系統 |
| 4 | 說後半句：畫面給前半句，學生說後半句；系統把兩半合起來檢查 | 2 | 句型由系統、合理由老師 |
| 5 | 自己說一整句 | 1 | 句型由系統、合理由老師 |

句型檢查規則（`assets/core/speechcheck.js`）：
- 只要……就……：含「只要」，之後含「就」，「只要」和「就」之間至少 2 個字，「就」之後至少 2 個字。
- 如果……不但……還……：依序含「如果」「不但」「還」，每兩個關鍵詞之間至少 2 個字，「還」之後至少 2 個字。
- 辨識常見誤字先換掉再檢查（例如「只有」→ 不算「只要」；「就」可寫作「就會」「就能」都算）。

### 4.3 修辭（rhetoric）
1. **認識卡**：擬人、譬喻、疊字、設問各一張，有圖示、簡單說法、課文例子（短到只有幾個字的引用，例如「筆芯三明治」）。
   - 擬人 🧑：把東西寫得像人一樣
   - 譬喻 🔁：把一樣東西比成另一樣東西
   - 疊字 👯：同一個字重複用
   - 設問 ❓：用問句引起你的好奇
2. **練習**（8 題，每種 2 題）：自動念出一個生活句，4 個選項是修辭圖示＋名稱，選這句用了什麼修辭。

### 4.4 共同規則
- 選擇題沿用 A 批：答錯三層提示（方法 → 線索 → 老師教你），提示不直接說出答案；按「下一題 ▶」才前進。
- 紀錄 activity 為 `phrase`／`pattern`／`rhetoric`；選擇題錯題進錯題複習，說說看的題目不進錯題複習（由老師批改處理）。
- 星星只算有系統判定的題目；等老師批改的題目不計入第一次答對率。

## 5. 🎤 說說看（`assets/ui/speak.js`）
1. 大大的 🎤 按鈕，按了開始聽（畫面顯示「我在聽……」），說完自動停止；也可以再按一次停止。
2. 顯示辨識出的文字（加注音），電腦念一次。按鈕：「✅ 送出」「🔁 重說」。
3. 送出後交給 `speechcheck`：
   - `correct`（在標準答案清單）→ 答對音效，可按下一題。
   - `bad`（句型不對）→ 三層提示：
     - 第 1 次：方法（例如「記得要用『只要』和『就』喔」）
     - 第 2 次：線索（例如「先說『只要……』，再說『就會……』」）
     - 第 3 次：老師教你：念一句示範句，學生再說一次；這次只要句型對就送出
   - `pending`（句型對、要老師判斷）→ 「已送出，等老師批改」，可按下一題。
4. 不支援語音辨識、或麥克風被拒絕：改顯示輸入框「請大人幫忙打字」。
5. 句子先放 outbox，有網路時送出（沿用 `api.js` 的 outbox）。

## 6. 後台

### 6.1 試算表新分頁「speech」
欄位：`id, ts, student, place, lesson, activity, qid, prompt, said, status, teacherNote, gradedAt`
- `status`：`auto`（系統判對）、`pending`、`ok`（老師判合理）、`redo`（老師請重說）
- 句子最多 200 字；`said` 存學生說的整句。

### 6.2 Apps Script 新動作
| 動作 | 需要老師登入 | 說明 |
|---|---|---|
| `speech` | 否 | 學生送出句子（id 重複就忽略） |
| `speechList` | 是 | 列出句子，可篩選學生、狀態 |
| `grade` | 是 | 設定 `ok`／`redo` 和 `teacherNote` |
| `feedback` | 否 | 傳入學生 id，只回傳這位學生已批改的句子（不含其他學生、不含名字） |

### 6.3 老師後台頁
多一個「📝 待批改」分頁：列出 `pending`（最新在上），可篩選學生。每筆：學生、題目、學生說的句子（🔊）、「✅ 合理」「🔁 再試一次」、選填「老師的話」。已批改的移到「已批改」區，可以再改。

### 6.4 學生端「老師的批改」頁
- 列出自己已批改的句子：✅ 得到 3 顆星；🔁 顯示「再說一次」按鈕，點了直接進那一題的說說看。
- 「老師的話」可點來聽，進入頁面自動念第一則。
- 看過的批改記在裝置上，課次卡片只顯示還沒看過的數量。
- 「再說一次」送出的是新的一筆（新 id、`pending`），舊的那筆保留 `redo` 給老師看進步。
- `feedback` 不用登入，只靠學生代號（例如 bear）查詢；回傳內容只有題目、句子、批改結果和老師的話，不含名字。

## 7. 資料格式（`data/lesson06.words.js` 擴充，公開、不加密）
```js
phrase: {
  intro: { parts: [...] },
  pick:  [{ id: 'ph1', img: 'apple-red.png', noun: '蘋果', options: ['紅通通','黑漆漆','綠油油','灰濛濛'], clue, explain }],
  say:   [{ id: 'ps1', img: 'apple-red.png', accept: ['紅通通的蘋果','紅紅的蘋果'], clue, model }],
  words: [{ word: '混合', meaning, img }],
  choose:[{ id: 'pw1', word: '混合', options: ['句子A','句子B'], clue, explain }],   // 第一個是對的
  make:  [{ id: 'pm1', word: '混合', clue, model }]
},
pattern: [{ key: 'zhiyao', title: '只要……就……', img, examples: [...],
  match: [{ id, front, options:[...], clue, explain }],
  conj:  [{ id, sentence: '＿＿你按一按，筆芯＿＿會跑出來。', options:['只要…就','如果…不但…還','因為…所以'], clue, explain }],
  half:  [{ id, front: '只要我每天練習，', clue, model }],
  whole: [{ id, clue, model }] }],
rhetoric: { cards: [...], quiz: [{ id, sentence, answer: '擬人', clue, explain }] }
```
- 題目 id 前綴全課唯一：`ph`、`ps`、`pw`、`pm`、`pt-`、`rh`。
- `wordsschema.js` 加驗證：正確答案在選項裡、選項不重複、id 不重複、說說看題目有 `clue` 和 `model`。

## 8. 錯誤處理
- 語音辨識沒聽到聲音（`no-speech`）：「我沒聽到，請再按 🎤 說一次」。
- 辨識服務連不上（`network`）：改用打字輸入框。
- `feedback` 連不上：課次卡片不顯示批改數量，其他功能照常。

## 9. 測試
- 單元：`speechcheck`（兩個句型的對錯、順序、太短、誤字）、`wordsschema` 新欄位、題目轉換、後台 `speech`／`grade`／`feedback` 的純邏輯（feedback 只回傳該學生）、`firstTryRate` 排除 pending。
- 端對端（以假的語音辨識模擬）：說說看 correct／bad 提示／pending；不支援時出現打字框；老師批改後學生看到「老師批改了 1 題」；句型五步能走完；修辭題答錯有提示。
- Claude 自我檢查：注音破音字、三聲變調（`SAY_FIX`）、台灣用語、提示不洩漏答案。
