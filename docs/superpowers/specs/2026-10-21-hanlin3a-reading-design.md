- 日期：2026-10-21
- 狀態：等待老師確認
- 參考網站：https://sped-teacher.github.io/Teaching-Materials/mandarin/#/（只參考做法，不複製程式碼）

## 1. 目標與範圍

### 1.1 目標
為資源班學生製作「翰林版三年級上學期國語」互動學習網站。第一版只做**第 6 課〈小鉛筆大學問〉的閱讀理解**。
學生在學校用電子白板全班一起操作，也能在家用家長的手機或平板練習。老師可以在後台看到每位學生的作答情形。

### 1.2 使用者
- 學生：目前 4 位，都有書寫和識字障礙，注音不熟，不能自己打字。
  之後可能換成不同能力的學生，所以題目要讓大多數學生都能用。
- 家長：從老師傳到 LINE 的任務連結進入網站。
- 老師：設定裝置、產生任務連結、看後台紀錄、加密課文。

### 1.3 第一版包含
- 首頁（12 課清單，只有第 6 課能點）
- 第 6 課的 5 個活動：聽課文、課文地圖、理解提問、錯題複習、單元測驗
- 老師設定（長按 ⚙️ 進入）、任務連結產生器
- 老師後台（老師密碼登入，資料存在老師的 Google 試算表）
- 課文加密和教室密碼解鎖、加密工具

### 1.4 第一版不包含
- 其他課次，以及生字、語詞、句型、造句等練習
- 多種難度（只有一種難度）
- 事先產生的語音檔（改用裝置內建語音）
- 任務連結自動解鎖課文
- 相容性實機測試（老師表示不需要）

### 3.2 作答畫面
```
┌───────────────────────────────┐
│ ← 返回   理解提問 🔊     ●●○○○ │
│   鉛筆的筆芯是用什麼做的？ 🔊   │
│  ┌─────────┐🔊  ┌─────────┐🔊 │
│  │ [圖片]  │    │ [圖片]  │    │
│  │ 石墨黏土 │    │   鉛    │    │
│  └─────────┘    └─────────┘    │
│  ┌─────────┐🔊  ┌─────────┐🔊 │
│  │ [圖片]  │    │ [圖片]  │    │
│  └─────────┘    └─────────┘    │
└───────────────────────────────┘
```
- 題目和每個選項旁邊都有 🔊。點 🔊 只念內容，不算作答。
- 點選項就直接作答。
- 答錯：馬上給提示（見 5.2），學生再選一次。
- 答對：鼓勵音效＋動畫，畫面下方出現「下一題 ▶」，學生按了才會進到下一題。
- 版面會依螢幕調整：橫式螢幕排成 2×2，直式手機排成 1 欄。點選區域至少 64×64 px（CSS px）。
- 題目預設不自動念；老師設定或任務連結 `auto=1` 可以打開。

### 3.3 學生身分
| 情況 | 處理方式 |
|---|---|
| 裝置設為全班模式（學校電子白板） | 紀錄算在 `class` |
| 網址帶 `s=` | 使用這個代號，並記在這台裝置；畫面上方顯示「🐻 小熊，加油！」 |
| 網址沒帶 `s=`，裝置也沒記過 | 顯示動物頭像讓學生點選（名冊從後台抓取；抓不到時用這台裝置上次存的名冊） |

### 3.4 老師設定（`#/settings`）
- 進入方式：長按 ⚙️ 2 秒 → 答對一題個位數乘法。
- 功能：
  - 裝置模式：全班，或指定某位學生
  - 題目自動念出來：開或關
  - 任務連結產生器：選學生、活動，可勾選自動念題目 → 按「複製連結」
  - 鎖定課文：清除這台裝置記住的金鑰
  - 前往老師後台、前往加密工具
  - 清除這台裝置的紀錄（要再確認一次）

## 4. 活動內容

### 4.1 聽課文（read）
- 依原本的段落顯示課文，包括兩個小標題「鉛筆的製作」「多樣的鉛筆」。
- 「▶ 從頭念」會一句一句念，正在念的句子會亮起來（每念完一句才換下一句，不依賴語音引擎回報字詞位置）。
- 每一段旁邊有 🔊。
- 本課語詞加底線：石墨、製成、部分、筆芯、斷裂、機器、凹槽、放入、另、三明治、筆桿、削鉛筆機。
  點一下會念出語詞，並跳出小卡（圖片＋簡單解釋＋🔊）。
- 完成條件：念完整篇，或按「我讀完了」。

### 4.2 課文地圖（map）：鉛筆是怎麼做出來的
- 7 個步驟，每個步驟一張圖卡：
  1. 石墨＋黏土
  2. 混合、加工成筆芯
  3. 木板做出凹槽
  4. 放入筆芯
  5. 黏上另一片木板（筆芯三明治）
  6. 切成筆桿
  7. 上色、加橡皮擦
- 圖卡打亂順序放在下方；點一張圖卡，就會放進下一個空格（不用拖曳）。每張圖卡都有 🔊。
- 放錯：圖卡彈回，並套用 5.2 的提示規則（這一格算一題）。
- 7 格都放對就算完成。

### 4.3 理解提問（quiz，10 題，每題 4 個選項）
| # | 題目 | 正確答案 | 類型 |
|---|---|---|---|
| 1 | 鉛筆是用「鉛」做的嗎？ | 不是 | 是非（選項：是／不是／有一半是／不知道） |
| 2 | 鉛筆是用哪些東西做的？ | 石墨、黏土、木頭 | 找資訊 |
| 3 | 鉛筆最重要的部分是什麼？ | 筆芯 | 找資訊 |
| 4 | 筆芯的原料有哪些？ | 石墨和黏土 | 找資訊 |
| 5 | 直接拿筆芯寫字，會怎麼樣？ | 容易斷、手會變黑 | 因果 |
| 6 | 為什麼要用木板把筆芯包起來？ | 保護筆芯、手不會黑 | 推論 |
| 7 | 機器先在木板上做出什麼？ | 凹槽 | 找資訊 |
| 8 | 「筆芯三明治」指的是什麼？ | 兩片木板中間夾著筆芯 | 詞義 |
| 9 | 哪一種鉛筆不用削？ | 自動鉛筆 | 找資訊 |
| 10 | 色鉛筆裡面沒有什麼？ | 石墨 | 找資訊 |

- 每題都附「依據句」，也就是課文裡跟答案有關的句子，提示時會念出來。
- 錯誤選項由 Claude 在原稿裡撰寫，交給老師確認。
- 每次作答時，選項順序都會打亂。

### 4.4 單元測驗（test）
- 題庫：理解提問 10 題，加上課文地圖延伸的 3 題排序題（例如「放入筆芯之前，要先做什麼？」），共 13 題。
- 每次隨機出 8 題，**不給提示**。
- 答錯時，標出正確答案，直接出現「下一題 ▶」。
- 分數是答對題數÷8，換算成百分比。這台裝置保留每位學生最近 3 次的分數，每次也都會送到後台。

### 4.5 錯題複習（review）
- 在理解提問、課文地圖或單元測驗中，**第一次沒答對**的題目，會加入這位學生在這台裝置上的複習清單。
- 距離上次練習這一題滿 1 天（以日曆日計算），這題才會出現在複習裡。
- 在複習中**連續 2 次第一次就答對**，這題就會從清單移除；答錯就重新計算。
- 複習時套用跟理解提問一樣的提示規則。
- 第 6 課選單上的「錯題複習」卡片，只有在有可以複習的題目時才會出現，並顯示題數。

## 5. 作答規則

### 5.1 單一難度
4 個選項、圖片＋文字、10 題理解提問、7 步課文地圖、8 題單元測驗。

### 5.2 答錯提示（理解提問、課文地圖、錯題複習）
| 答錯次數 | 處理方式 |
|---|---|
| 第 1 次 | 選錯的選項變淡、不能再點；念「再想想看」，再念出依據句 |
| 第 2 次 | 選錯的選項變淡，並另外刪掉一個錯誤選項（只剩正確答案和一個錯誤選項） |
| 第 3 次 | 只剩正確答案（一定會答對） |

每題記錄的結果：`first`（第一次就答對）、`hint1`（答錯 1 次後答對）、`hint2`（答錯 2 次以上後答對），以及每次選錯的選項文字。

### 5.3 星星
| 第一次答對率 | 星星 |
|---|---|
| 80% 以上 | ⭐⭐⭐ |
| 50% 以上 | ⭐⭐ |
| 其他（只要完成） | ⭐ |

聽課文完成就給 ⭐⭐⭐。這台裝置記錄每位學生在每個活動拿過的最高星數，顯示在活動卡片上。

## 6. 聲音（TTS）
- 使用 `speechSynthesis`。選擇語音的優先順序：`zh-TW` → `zh-Hant` → 名稱含「Taiwan」或「臺灣」的語音 → 其他 `zh` 語音。
- 找不到任何中文語音時，畫面上方會顯示提示條「這台裝置沒有中文語音」，並附 iPhone、Android、Windows 的下載步驟。
- 讀音修正：每段文字可以另外設定 `say` 欄位（念的時候用同音字替換），用來修正破音字。在原稿中個別設定。
- 播放新的語音之前，會先停止正在念的語音。
- iOS 要使用者先點過畫面才能發出聲音，所以第一次點擊時會先播一段無聲語音來啟動。

## 7. 紀錄與老師後台

### 7.1 裝置本機儲存（localStorage，讀寫都用 try/catch 包起來）
| 鍵 | 內容 |
|---|---|
| `h3a.settings` | 裝置模式、目前學生 id、自動念題目開關 |
| `h3a.roster` | 最近一次抓到的名冊（id、emoji、名稱） |
| `h3a.key` | 教室密碼推導出的 AES 金鑰（base64） |
| `h3a.progress.<學生>` | 各活動最高星數、單元測驗最近 3 次分數 |
| `h3a.review.<學生>` | 複習清單：題號 → {上次練習日期, 連續答對次數} |
| `h3a.outbox` | 還沒成功送出的紀錄（陣列） |

### 7.2 送出的紀錄格式
```json
{
  "id": "隨機 uuid（避免重複寫入）",
  "ts": "2026-10-21T19:32:00+08:00",
  "student": "bear | class",
  "place": "home | school",
  "lesson": "L06",
  "activity": "read | map | quiz | review | test",
  "items": [{"q": "q5", "result": "hint1", "wrong": ["手會變白"]}],
  "firstTryRate": 0.7,
  "score": null,
  "stars": 2,
  "durationSec": 380
}
```
`place`：全班模式是 `school`，其他是 `home`。
送出失敗時，紀錄會先放進 outbox，下次開網站或網路恢復（`online` 事件）時再補送。

### 7.3 Google Apps Script 後端（老師自己的 Google 試算表）
- 試算表有兩個工作表：`records`（每筆紀錄一列，`items` 存成 JSON 字串）、`roster`（id、emoji、名稱）。
- 部署成網頁應用程式：以老師的身分執行，任何人都可以存取。
- 網站端一律用 `POST`，`Content-Type: text/plain`，避免跨網域預檢請求（CORS preflight）。
- API（body 是 JSON，用 `action` 欄位區分）：

| action | 需要登入 | 功能 |
|---|---|---|
| `submit` | 否 | 寫入一筆紀錄；用 `id` 去除重複；檢查欄位格式和長度 |
| `roster` | 否 | 回傳名冊（只有 id、emoji、名稱） |
| `login` | 否 | 比對 Script Properties 裡的 `TEACHER_PASSWORD`；成功就發 token（存在 CacheService，2 小時沒操作就失效）；連續失敗 5 次就鎖住 15 分鐘 |
| `records` | 是 | 依學生、活動、日期篩選紀錄 |
| `saveRoster` | 是 | 新增或修改名冊 |

- 後端網址（Apps Script 部署網址）寫在網站的 `config.js`。這個網址可以公開，因為讀取紀錄必須有 token。

### 7.4 老師後台（`#/teacher`）
- 登入畫面：輸入老師密碼。
- 紀錄列表：可依學生、活動、日期（今天／本週／全部）篩選。每列顯示學生、活動、日期、答對率或分數、星星，以及「看細節」。
- 細節：每一題的結果和選錯的選項。
- 「最常錯的題目」：在目前的篩選條件下，依第一次沒答對的次數排序，列出前 5 題。
- 名冊管理：新增、改名、選 emoji。
- 2 小時沒有操作就登出（token 失效）。

## 8. 課文加密

### 8.1 加密範圍
第 6 課的完整資料（課文、語詞解釋、題目、選項、依據句、讀音修正）整份加密，存成 `data/lesson06.enc.js`。
不加密的公開資料 `data/lessons.js` 只有課次清單（課名、可不可以點）。

### 8.2 加密方式
- 金鑰：PBKDF2-SHA256，迭代 250,000 次，產生 256 位元的 AES-GCM 金鑰。
- 鹽值：全站共用一個 16 位元組的隨機鹽值，存在 `data/crypto.js`。這樣同一組教室密碼可以解開所有課次，裝置只需要記住一把金鑰。
- 每份檔案用自己的 12 位元組隨機 IV。
- 檔案格式：
  ```js
  window.ENC = window.ENC || {};
  ENC.L06 = { v: 1, iv: "<base64>", ct: "<base64>" };
  ```
- 解密成功後，把金鑰匯出成 base64，存到 `h3a.key`。

### 8.3 流程（教室密碼不經過 Claude）
1. Claude 把第 6 課整理成原稿 `lesson06.json`，放到老師的 Google 雲端硬碟。不放進 repo，repo 的 `.gitignore` 會排除 `*.plain.json`。
2. 老師開啟 `#/teacher/encrypt`，選擇原稿檔，輸入教室密碼兩次，下載 `lesson06.enc.js`。加密完全在老師的裝置上進行。
3. 老師把 `lesson06.enc.js` 放回 Google 雲端，Claude 再放進 repo。

### 8.4 限制
知道密碼的人都能看到內容。密碼輸入畫面會顯示「課文有著作權，密碼請勿外流」。

- `core/` 裡的每個檔案同時支援瀏覽器（掛在全域 `H3A` 上）和 Node（`module.exports`），不需要打包工具。

## 11. 錯誤處理
| 情況 | 處理方式 |
|---|---|
| 沒有中文語音 | 顯示提示條和下載說明；網站其他功能照常可以用 |
| localStorage 不能用（無痕模式等） | 網站可以照常作答，只是不會記住任何東西；會送出紀錄，但失敗時不能補送 |
| 後端連不上 | 紀錄先放進 outbox；後台顯示「無法連線」 |
| 教室密碼錯誤 | 顯示「密碼不對，請問老師」，可以重試 |
| 這台裝置的金鑰解不開新的加密檔（換過密碼） | 清除舊金鑰，重新要求輸入密碼 |
| 圖片缺少 | 顯示灰色框加文字 |
| 名冊抓不到 | 用這台裝置存的名冊；兩者都沒有時，只能選「全班」 |

## 12. 測試
- 單元測試（`node --test`）：scoring、hints、review、links、quizgen、cryptobox 的加密和解密來回，以及錯誤密碼。
- 後端：`Code.gs` 的純邏輯（驗證、去除重複、鎖定計數）抽成可以在 Node 測試的函式。
- 端對端：用 Playwright（Chromium）跑主要流程：
  - 輸入密碼解鎖
  - 完成理解提問：答錯出現提示，答對才出現「下一題」
  - 課文地圖排序
  - 單元測驗
  - 錯題複習出現的條件
  - 老師設定產生的連結正確
  - 後端用假的伺服器模擬
- 語音和實機不做自動測試，由老師上課使用時回報問題。
