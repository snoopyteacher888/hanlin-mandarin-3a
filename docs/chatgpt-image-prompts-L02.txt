第 2 課〈妙用便利貼〉圖片：給 ChatGPT 的指令（共 77 張）

【使用方法，跟上次一樣】
1. 一次只貼「一張圖」的指令給 ChatGPT。等它畫完、下載好，再貼下一張。
2. 每一張都要「整段」複製，從「請幫我畫一張圖」開始，到最後一個「。」結束。
3. 下載後，把檔名改成指令上方寫的檔名（全部小寫英文，例如 sticky-note.png）。
4. 全部畫好後，上傳到 GitHub 的 images/L02/ 資料夾（注意：是 L02），然後告訴 Claude。
5. 如果 ChatGPT 畫成很多格、四格漫畫、或圖裡有字，直接回覆它：
　「不對。請重畫：只要一張圖，不要分格，不要任何文字，白色背景，正方形。」
6. 每畫好一張，就在 □ 打勾。
