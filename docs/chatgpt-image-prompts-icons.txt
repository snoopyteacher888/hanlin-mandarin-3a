網站「活動圖示」：給 ChatGPT 的指令（共 16 張）

【使用方法】
1. 一次只貼「一張圖」的指令給 ChatGPT。等它畫完、下載好，再貼下一張。
2. 為了讓 16 張風格一樣，建議在「同一個對話」裡一張一張畫。畫第 2 張以後，可以多加一句：「風格要跟前面幾張一樣。」
3. 下載後，把檔名改成指令上方寫的檔名（全部小寫英文，例如 map.png）。
4. 全部畫好後，上傳到 GitHub 的 images/icons/ 資料夾（新的資料夾），然後告訴 Claude。
5. 如果 ChatGPT 畫成很多格或圖裡有字，直接回覆它：「不對。請重畫：只要一張圖，不要任何文字，白色背景，正方形。」
6. 還沒上傳的圖示，網站上會先顯示原本的小圖案，不會壞掉。
